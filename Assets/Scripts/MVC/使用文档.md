# MVC UI 框架使用文档

## 一、架构概述

本框架采用 **MVC（Model-View-Controller）** 模式构建 UI 系统，核心目标是将**数据、逻辑、显示**三者解耦。

```
┌─────────────────────────────────────────────────────┐
│                   ControllerManager                  │
│         管理所有 Controller 的注册与通信              │
└──────────┬──────────────────────────┬───────────────┘
           │                          │
    ┌──────▼──────┐            ┌──────▼──────┐
    │ Controller  │◄──────────►│ Controller  │  ← 跨控制器通信
    └──┬──────┬───┘            └──┬──────┬───┘
       │      │                   │      │
   ┌───▼──┐ ┌─▼────┐        ┌───▼──┐ ┌─▼────┐
   │Model │ │ View │        │Model │ │ View │
   └──────┘ └──────┘        └──────┘ └──────┘

通信方向：
  View ──Action事件──► Controller ──方法调用──► View（渲染）
  Controller ──GameEvents──► 外部模块
  外部模块 ──GameEvents──► Controller ──► View（渲染）
```

### 核心角色

| 角色 | 文件 | 职责 |
|------|------|------|
| **Model** | `BaseModel.cs` | 持有数据，被 Controller 读写 |
| **View** | `BaseView.cs`, `IBaseView.cs` | 显示 UI、响应用户输入，通过 Action 通知 Controller |
| **Controller** | `BaseController.cs` | 协调 Model/View，处理业务逻辑，订阅全局事件 |
| **ControllerManager** | `ControllerManager.cs` | 管理所有 Controller 的注册、初始化、跨控制器通信 |
| **ViewManager** | `ViewManager.cs` | 管理所有 View 的加载、打开、关闭、缓存、销毁 |

### 文件结构

```
mvc/
├── BaseModel.cs              # 模型基类
├── IBaseView.cs              # 视图接口
├── BaseView.cs               # 视图基类（MonoBehaviour）
├── BaseController.cs         # 控制器基类
├── ControllerManager.cs      # 控制器管理器
├── ViewManager.cs            # 视图管理器
├── ControllerType_Template.cs # 控制器类型枚举模板
├── ViewType_Template.cs      # 视图类型枚举模板
└── 使用文档.md                # 本文档
```

## 二、快速开始

### 步骤 1：复制核心文件

将所有 `.cs` 文件复制到项目的 `Scripts/` 目录下。

### 步骤 2：创建 Model（数据）

```csharp
public class PlayerModel : BaseModel
{
    public int Level;
    public int Hp;
    public string Name;

    public override void Init()
    {
        Level = 1;
        Hp = 100;
        Name = "Player";
    }
}
```

### 步骤 3：创建 View（界面）

```csharp
public class PlayerInfoView : BaseView
{
    [SerializeField] private TextMeshProUGUI nameText;
    [SerializeField] private TextMeshProUGUI levelText;

    protected override void OnAwake()
    {
        base.OnAwake();
        // 自举 Controller（可选：也可由外部注入）
        if (Controller == null)
        {
            var ctl = new PlayerInfoController();
            Controller = ctl;
            ctl.OnLoadView(this);
            ctl.Init();
        }
    }

    // View 提供渲染方法，由 Controller 调用
    public void Render(PlayerModel model)
    {
        nameText.text = model.Name;
        levelText.text = $"Lv.{model.Level}";
    }
}
```

### 步骤 4：创建 Controller（逻辑）

```csharp
public class PlayerInfoController : BaseController
{
    private PlayerInfoView _view;
    private PlayerModel _model;

    public override void Init()
    {
        _model = new PlayerModel();
        SetModel(_model);

        // 订阅全局事件
        GameEvents.Listen(EventType.PLAYER_ON_LEVEL_UP, OnLevelUp);
    }

    public override void OnLoadView(IBaseView v)
    {
        _view = v as PlayerInfoView;
        // View 加载后立即渲染
        _view?.Render(_model);
    }

    public override void Destroy()
    {
        base.Destroy();
        GameEvents.Unlisten(EventType.PLAYER_ON_LEVEL_UP, OnLevelUp);
    }

    private void OnLevelUp(IGameEvent evt)
    {
        _model.Level++;
        _view?.Render(_model);  // 数据变化 → 更新 View
    }
}
```

### 步骤 5：注册并初始化

```csharp
// 在游戏入口（如 GameApp.Start()）中执行
void Start()
{
    // 1. 创建 Controller
    var playerCtl = new PlayerInfoController();

    // 2. 注册到 ControllerManager
    ControllerManager cm = new ControllerManager();
    cm.Register(ControllerType.Player, playerCtl);
    cm.InitAllModule();

    // 3. 注册视图到 ViewManager
    ViewManager vm = new ViewManager();
    ViewInfo info = new ViewInfo(
        prefabName: "PlayerInfoView",
        parent: vm.CanvasTf,
        controller: playerCtl,
        viewTypeName: "PlayerInfoView",
        sortingOrder: 10
    );
    vm.Register(ViewType.PlayerInfoView, info);

    // 4. 打开视图
    vm.Open(ViewType.PlayerInfoView);
}
```

## 三、API 参考

### 3.1 BaseController

| 方法 | 说明 |
|------|------|
| `Init()` | 初始化控制器，订阅全局事件、创建 Model |
| `OnLoadView(IBaseView)` | View 加载完成回调，绑定 View 事件 |
| `OpenView(IBaseView)` | View 打开回调 |
| `CloseView(IBaseView)` | View 关闭回调 |
| `Destroy()` | 销毁，清理事件订阅 |
| `SetModel(BaseModel)` | 设置模型并双向绑定 |
| `GetModel<T>()` | 获取类型安全的模型 |
| `RegisterFunc(name, callback)` | 注册控制器内部消息 |
| `ApplyFunc(name, args)` | 触发控制器内部消息 |
| `ApplyControllerFunc(key, name, args)` | 向其他控制器发送消息 |
| `InitGlobalEvent()` / `RemoveGlobalEvent()` | 全局事件订阅/取消订阅钩子 |

### 3.2 BaseView

| 方法 | 说明 |
|------|------|
| `InitUI()` | 初始化 UI 组件绑定 |
| `InitData()` | 初始化数据，设置 `_isInit = true` |
| `Open(args)` | 视图打开 |
| `Close(args)` | 视图关闭（默认隐藏 Canvas） |
| `DestroyView()` | 销毁 GameObject |
| `SetVisible(bool)` | 控制 Canvas 显隐 |
| `Find(string)` | 按路径查找子物体（带缓存） |
| `Find<T>(string)` | 按路径查找子物体上的组件（带缓存） |
| `ApplyFunc(name, args)` | 向所属 Controller 发送消息 |
| `OnAwake()` / `OnStart()` | Unity 生命周期钩子 |

### 3.3 ViewManager

| 方法 | 说明 |
|------|------|
| `Register(key, ViewInfo)` | 注册视图配置 |
| `Open(key, args)` | 打开视图（自动加载 Prefab 并实例化） |
| `Close(key, args)` | 关闭视图 |
| `CloseAll()` | 关闭所有视图 |
| `Destroy(key)` | 销毁视图及 GameObject |
| `IsOpen(key)` | 视图是否已打开 |
| `GetView<T>(key)` | 获取视图实例 |
| `RemoveView(key)` | 从所有字典中清除视图 |

### 3.4 ViewInfo 配置

```csharp
public class ViewInfo
{
    public string PrefabName;     // Prefab 名称（Resources 路径）
    public Transform ParentTf;    // 父节点
    public BaseController Controller; // 关联的控制器
    public int SortingOrder;      // Canvas 渲染层级
    public string ViewTypeName;   // 视图脚本类型名（用于 AddComponent）
}
```

## 四、生命周期

### Controller 生命周期

```
new Controller()
    │
    ▼
SetModel(model)         ← 设置数据模型
    │
    ▼
ControllerManager.Register(key, ctl)
    │
    ▼
Init()                  ← 初始化：订阅全局事件、创建 Model
    │
    ▼
OnLoadView(view)        ← View 加载完成：绑定 View 事件、首次渲染
    │
    ▼
┌─ OpenView(view) ──► CloseView(view) ──┐  循环
│  （View 打开时）     （View 关闭时）    │
└────────────────────────────────────────┘
    │
    ▼
Destroy()               ← 销毁：取消所有订阅
```

### View 生命周期

```
Instantiate Prefab
    │
    ▼
Awake() → OnAwake()    ← 绑定 UI 组件引用
    │
    ▼
Start() → OnStart()
    │
    ▼
InitUI()                ← 初始化 UI 状态
    │
    ▼
InitData()              ← 标记 _isInit = true
    │
    ▼
Open(args)              ← 显示视图
    │
    ▼
SetVisible(true)        ← Canvas.enabled = true
    │
    ▼
Close(args)             ← 关闭视图
    │
    ▼
DestroyView()           ← 删除 GameObject
```

## 五、通信模式

### 模式 1：View → Controller（Action 事件）

View 通过 C# `event`/`Action` 将用户交互通知 Controller：

```csharp
// View 定义事件
public class MyView : BaseView
{
    public event Action<int> ItemClicked;

    void OnButtonClick()
    {
        ItemClicked?.Invoke(selectedIndex);
    }
}

// Controller 绑定事件
public override void OnLoadView(IBaseView v)
{
    var view = v as MyView;
    view.ItemClicked += HandleItemClicked;
}

private void HandleItemClicked(int index)
{
    // 业务处理...
}
```

### 模式 2：Controller → View（方法调用）

Controller 直接调用 View 的渲染方法：

```csharp
_view?.Render(data);
_view?.UpdateList(items);
```

### 模式 3：外部模块 → Controller（GameEvents）

外部模块通过 `GameEvents.Publish()` 通知 Controller，Controller 再更新 View：

```csharp
// Controller 订阅
GameEvents.Listen(EventType.PLAYER_ON_DAMAGE, OnPlayerDamage);

void OnPlayerDamage(IGameEvent evt)
{
    _model.Hp -= (evt as PlayerValueEventArgs).Value;
    _view?.RenderHp(_model.Hp);  // 驱动 View 更新
}
```

### 模式 4：跨 Controller 通信

```csharp
// 通过 ControllerManager 转发
controllerManager.ApplyFunc(ControllerType.QuestLog, "AddLog", entry);
```

## 六、最佳实践

### 6.1 Controller 负责 View 的渲染

```
❌ 错误：View 内部自己做数据查询和逻辑
    View 中写: nameText.text = PlayerManager.Instance.GetName();

✅ 正确：Controller 把数据传给 View
    Controller: _view.Render(model);
    View: nameText.text = model.Name;
```

### 6.2 订阅与取消订阅配对

```csharp
public override void Init()
{
    GameEvents.Listen(EventType.GAME_EVENT_ON_PAUSE, OnPause);
}

public override void Destroy()
{
    base.Destroy();
    GameEvents.Unlisten(EventType.GAME_EVENT_ON_PAUSE, OnPause);
    // 同时解绑 View 的事件
    if (_view != null)
    {
        _view.ButtonClicked -= HandleButtonClick;
    }
}
```

### 6.3 View 只做纯展示

```csharp
// ✅ View 只负责 UI 操作
public class MyView : BaseView
{
    public void RenderHp(int hp) => hpText.text = $"HP: {hp}";
    public event Action AttackClicked;
}

// ✅ 业务逻辑全在 Controller
public class MyController : BaseController
{
    void HandleAttack() { /* 检查条件、计算伤害... */ }
}
```

### 6.4 场景切换时清理

```csharp
void OnSceneUnload()
{
    viewManager.CloseAll();
    controllerManager.ClearAllModules();
}
```

## 七、如何接入新项目

### Unity 项目

1. 将所有 `.cs` 文件放入 `Assets/Scripts/MVC/`
2. 在场景中创建名为 `Canvas` 的根物体（ViewManager 会自动查找）
3. 创建 Prefab 放入 `Assets/Resources/View/` 目录
4. 定义你的 `ControllerType` 和 `ViewType` 枚举
5. 创建 GameApp 入口脚本，初始化 ViewManager 和 ControllerManager

### 非 Unity / 自定义加载

重写 `ViewManager.LoadView()` 方法以适配 AssetBundle、Addressables 等加载方式：

```csharp
protected override IBaseView LoadView(int key, ViewInfo viewInfo)
{
    // 使用 Addressables 加载
    var handle = Addressables.InstantiateAsync(viewInfo.PrefabName, viewInfo.ParentTf);
    // ...
}
```

## 八、注意事项

| 问题 | 说明 |
|------|------|
| Controller 泄漏 | 确保每个 Controller 在 Destroy 中取消所有 GameEvents 订阅 |
| View 重复打开 | ViewManager.Open() 已做防护，重复 Open 不会创建新实例 |
| Canvas 缺失 | 确保场景中存在名为 `Canvas` 的根物体，或手动赋值 `ViewManager.CanvasTf` |
| 类型名匹配 | `ViewType` 枚举值名需与实际的 View 类名一致（或用 `ViewTypeName` 指定） |
| BaseView.Find | 首次查找会缓存，适合一次性绑定的 UI 元素。动态列表不建议缓存 |

---

> 核心原则：**Model 管数据，View 管显示，Controller 管逻辑。三者单向依赖：View 不知道 Model 存在，Model 不知道 View 存在。**
